# RIFT//RUN

Open `index.html` in any modern browser to play.

- Press **Space**, **W**, **Up**, or click/tap to jump.
- Hold the input while in Ship or Wave mode to fly; click to flap upward in UFO mode.
- Touch portals to change form (Cube, Ship, Robot, Wave, Spider, Swing, or UFO), avoid hazards, and reach the exit rift.
- Choose Drift, Pressure, or Blackout from the level rail.
- Press **R** after a crash to replay.
